# 🌍 TraversalCoreProje  
Ein vollständiges Reiseverwaltungs‑ und Buchungssystem basierend auf ASP.NET Core MVC

TraversalCoreProje ist ein umfangreiches, mehrschichtiges Webprojekt, das eine komplette Reiseplattform bereitstellt – inklusive moderner Benutzeroberfläche, Blog‑Bereich, Reservierungssystem, Benutzerprofilen und einem leistungsstarken Admin‑Dashboard.  
Das Projekt kombiniert **professionelles UI‑Design**, **saubere Architektur**, **Entity Framework Core**, **Repository Pattern** und **vollständige CRUD‑Funktionalitäten**.

---

## ✨ Hauptfunktionen

### 🖥️ Benutzer‑Frontend
Das öffentliche Frontend bietet eine moderne, benutzerfreundliche Oberfläche:

- **Startseite** mit Suchfunktion (Reiseziel + Datum)
- **Beliebteste Reiseziele** mit Bildern, Preisen und Kurzbeschreibung
- **Detailseiten** für jedes Reiseziel  
  - Bildergalerien  
  - Beschreibung  
  - Historische Informationen  
  - Kulinarische Erlebnisse  
  - Aktivitäten & Highlights  
  - Preis, Kapazität, Dauer (Tag/Nacht)  
  - Reservierungsbutton
- **Blog‑System**  
  - Artikel mit Titel, Autor, Datum, Lesezeit  
  - Bilder, Abschnitte, Tags  
- **Kommentare**  
  - Benutzer können Kommentare hinterlassen  
  - Anzeige von Datum, Status, Profilbild
- **Benutzerprofil**  
  - Persönliche Daten anzeigen  
  - Profil bearbeiten  
  - Passwort ändern  
  - Profilbild hochladen

---

## 🛠️ Admin‑Dashboard (Backend)
Das Admin‑Panel ist vollständig funktionsfähig und bietet alle Werkzeuge zur Verwaltung der Plattform:

### 📊 Dashboard
- Website‑Besucher (mit Wachstum/Trend)
- Kundenstatistik
- Neue Reiseziele
- Reservierungen (mit Status)

### 🧭 Reiseziele verwalten
- Liste aller Reiseziele
- Status (Aktiv/Deaktiviert)
- Details ansehen
- Bearbeiten
- Löschen
- **Neues Reiseziel erstellen**  
  - Titel  
  - Beschreibung  
  - Kapazität  
  - Preis  
  - Dauer  
  - Bilder hochladen  
  - **Live‑Preview** der Seite

### 🗂️ Reservierungen
- Ausstehende Reservierungen
- Bestätigte Reservierungen
- Stornierte Reservierungen
- Neue Reservierungen
- Pagination

### 💬 Kommentare
- Alle Kommentare anzeigen
- Status (aktiv/inaktiv)
- Löschen
- Reiseziel anzeigen

### 👤 Benutzerverwaltung
- Benutzerliste
- Profilbild
- Name, Nachname, E‑Mail
- Kommentare des Benutzers anzeigen
- Bearbeiten
- Löschen
- Neuen Benutzer hinzufügen
